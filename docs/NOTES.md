# About the notes the code refers to

Comments in the code and in the tools often point at a file such as
`docs/launcher-design.md` or `docs/plan-a-persistent-image.md`. Those are the
author's working notes: a dated record of measurements, dead ends and bench
sessions on one particular unit. They are not published. What is needed to
understand, build and install the firmware is in this directory and in
`design/`; where a comment's reference would have told you more, the comment
itself usually carries the conclusion.
