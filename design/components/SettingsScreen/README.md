A settings list, opened here on Display: a `title-36` header and up to seven 60px rows across the screen, as the car's own lists. There is no help text and no side panel, as in the car's own settings; a row's label has to explain itself.

Row kinds shown: an amount (Brightness: push to adjust, turn, push to keep; or tap − and +) and choices (a push steps to the next value). Amount rows share fixed columns from the right edge, in the order of the car's own tone settings: plus 60px, bar 200px, minus 60px, then the number, so bars line up down the screen whatever the label length.
